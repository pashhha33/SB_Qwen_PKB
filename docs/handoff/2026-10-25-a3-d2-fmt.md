## Что это

**Под-батч A3 — последний кусок этапа A.** Две вещи:

**1. D2 — генератор TypeScript-типов из JSON Schema** (пункт D2 чек-листа готовности;
конструкция принята давно — DL-222, ответ 9-2 = А). Типы **не пишутся руками**: единственный
источник истины — схемы `schema/**` в корне репозитория.

- Скрипт `plugin/scripts/generate-schema-types.mjs` на `json-schema-to-typescript`
  (новая dev-зависимость) читает 13 схем (6 метамодели + 6 предметных типов + строка
  `.jsonl`) и пишет **13 файлов в `plugin/src/generated/`** — они **коммитятся**.
- Команды: `npm run generate:types` (перегенерировать) и `npm run check:types-fresh`
  (только сверка). Тест `generated-freshness.test.ts` запускает сверку на каждом `npm test`:
  «перегенерация == зафиксированное» — расхождение «схема ↔ типы» исключено конструкцией.
- Честная граница (M6): условные блоки `if/then/else` генератор уплощает — типы являются
  приближением к схеме; норма — сама схема и рантайм-валидация плагина.
- С этим пунктом **чек-лист готовности закрыт целиком: 32 из 32** (`readiness-checklist` v0.26.0).

**2. `front-matter-title-adapter`** (модуль этапа A; карточка `docs/integrations/front-matter-title.md`).
Front Matter Title (FMT) — сторонний необязательный плагин, который показывает `title` из
frontmatter вместо технического имени файла (`BOOK-01J….md`) в проводнике, вкладках и поиске
(уровень 2 читаемости ADR-001). Наш адаптер его только **обнаруживает** и **один раз
рекомендует** поставить, если его нет (повтор не пристаёт — флаг `fmtAdviceShown` в
`.sb/settings.json`). Никакого управления чужим плагином (публичного API у FMT нет);
сбой адаптера деградирует молча (М3); без FMT всё работает — показываются имена файлов (М4).

Версии: плагин **0.4.0 → 0.5.0** (MINOR); метамодель **не менялась (1.2.0)** — CHANGELOG
**[1.2.3]** (учётная запись). Тесты: **157 → 165** (+8). **Этап A закрыт**: все 5 чек-боксов
DoD ✅ (`phases.md` v0.9.0).

   находку «версия 0.3.1» из вашего журнала.
2. Перезагрузите Obsidian (`Ctrl+R` или «Reload app without theme»). Ожидание:
   - Notice **«Second Brain 0.5.0: загружен (типов в реестре: 7)»** — версия исправилась;
   - если Front Matter Title **не установлен**: один рекомендательный Notice («Рекомендуем
     необязательный плагин Front Matter Title…»). При следующей перезагрузке он **не
     повторяется** (флаг в `.sb/settings.json`);
   - если установлен и включён — никаких новых Notice.
3. `Ctrl+P` → **show-log**: запись области `front-matter-title` (info — «не установлен…/
   установлен, но выключен…», debug — «установлен и включён (версия …)»).
4. Бутстрап по-прежнему идемпотентен: запись `bootstrap … все 7 определений уже существуют —
   пропуск` (debug), Notice бутстрапа отсутствует.
