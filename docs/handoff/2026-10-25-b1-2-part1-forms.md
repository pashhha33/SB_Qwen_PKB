## Что это

**B1.2 «формы и контролы», часть 1** — первое включение Svelte и форма свойств объекта:

**1. Форма `edit-object`** (`Ctrl+P` → «Редактировать объект (форма)»): свойства объекта
полям с **русскими подписями** (LabelResolver), тип значения определяет контрол:
перечисление — выпадающий список, число — числовое поле с **живым предпросмотром звёзд
или прогресса** (`display.*`, DL-123), дата/дата-время — поле с подсказкой формата
(частичные даты через «00»), логическое — галочка, ссылка — поле с шаблоном канонической
ссылки; множественные значения (0..N/1..N) — строки с кнопками «+ добавить» / «×».

**2. Условные поля работают как в метамодели (М1–М7)**: видимость полей с `applies_when`
пересчитывается **живьём при вводе** — выберите `format: web_novel`, и поле `platform`
появится; переключите на `file` — исчезнет, но введённое значение **сохранится в данных**
(М2 — молчаливое удаление запрещено; при сохранении скрытые значения записываются как есть).

**3. Уровень 1 контроля (ADR-011)**: некорректное значение (не число, дата «32 января»,
кириллица в перечислении, значение вне списка) подсвечивается ошибкой под полем и
**блокирует кнопку «Сохранить»**. А вот отсутствие обязательного поля сохранению **не
мешает** (DL-183 «сначала объект, потом поля») — недостающее покажет validate-object.

**4. Запись** (`object-service`): title + синхронизация `aliases[0]` (И4), `updated_at`
обновляется (И5), неизвестные поля frontmatter сохраняются, служебные свойства
(`sb_issues`) и `archived` в форму не попадают (08-views §7). Тело заметки не трогается
(processFrontMatter).

**5. Команда `toggle-label-mode`**: русские подписи (view) ↔ технические ключи (source) —
режим сохраняется в `.sb/settings.json` (ADR-003).

**6. `create-object` теперь открывает форму сразу после создания** (сбой формы не отменяет
создание — объект уже записан).

**7. `create-property` поддерживает `display.*`**: способ показа (plain/stars/progress),
предел шкалы, единица измерения — для числовых свойств (звёзды рейтинга, прогресс).

**Границы части 1 (честно, M6 — architecture.md §5, B1.2-1…5)**: контрол ссылки —
текстовое поле (подбор цели поиском — часть 2); TypeScript внутри `.svelte` не
проверяется `tsc` (вся логика — в ядре, оно покрыто тестами); `categories`/`tags` в форме
не редактируются (категории — B1.3, метки — штатная панель Obsidian); `display_template.*`
перенесены на этап D (носитель — представления); определения метамодели через форму не
правятся (только команды create-* — ADR-004).

Версии: плагин **0.7.0 → 0.8.0**; метамодель **1.3.0** (без изменений); тесты **263 → 299** (+36).

## Шаг 4. После применения — ручная проверка в Obsidian (5 минут, сценарий критерия B1)

1. Перенесите в папку плагина хранилища **`main.js` и `manifest.json`** (или
   `npm run link:vault`), перезагрузите Obsidian. Ожидание: Notice
   **«Second Brain 0.8.0: загружен (типов в реестре: 7)»**.
2. Соберите мини-книгу командами (`Ctrl+P`):
   - **create-object-type**: ключ `book`, подпись «Книга», префикс `BOOK` → создан;
   - **create-property**: ключ `format`, подпись «Формат», тип `text`, кардинальность
     `1`, область `specific`, типы `book`, значения перечисления `file, web_novel` → создан;
   - **create-property**: ключ `platform`, подпись «Площадка», тип `text`, кардинальность
     `1`, область `specific`, типы `book`, условие: триггер `format`, операция `equals`,
     значения `web_novel` → создан;
   - **create-property**: ключ `rating`, подпись «Оценка», тип `number`, кардинальность
     `0..1`, область `specific`, типы `book`, показ `stars`, предел `10` → создан.
3. **create-object** → тип «Книга» → название «Тестовая книга» → **форма откроется
   сама**: видны поля «Формат» (список), «Оценка» (со звёздами), «Автор»… нет — только
   созданные свойства. Проверьте:
   - выберите `format = web_novel` → **появилось поле «Площадка»**; введите что-нибудь,
     переключите `format = file` → поле исчезло; верните `web_novel` → **значение на месте** (М2);
   - введите в «Оценка» число 7 → **предпросмотр `★★★★★★★☆☆☆ 7/10`** рисуется живьём;
   - в «Формат» через список выберите значение, затем в поле даты (если создадите)
     введите `32 января` — ошибка под полем, «Сохранить» заблокирована (уровень 1);
   - **Сохранить** → Notice «Сохранено: BOOK-….md»; в заметке — значения, `updated_at`
     обновлён, `aliases[0]` = названию.
4. **edit-object** на той же заметке — форма открылась с уже введёнными значениями.
5. **toggle-label-mode** → подписи стали техническими ключами (`format`, `rating`);
   повторно — вернулись русские.
6. **validate-object** на заметке — нарушений нет (или понятные: обязательное «Формат»
   при пустом значении — `value.cardinality`).
7. Журнал (`show-log`): записи областей `creation` (создания), `edit` (сохранение формы),
   `settings` (режим подписей).

Если что-то не так — `Ctrl+P` → **copy-log** и вставьте журнал в чат.
