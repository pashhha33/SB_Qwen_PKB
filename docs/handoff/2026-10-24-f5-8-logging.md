## После применения — ручная проверка в Obsidian (2–3 минуты)

1. Пересоберите dev-связку, если нужно (`npm run build` уже сделан), перезагрузите
   плагин: Настройки → Сторонние плагины → Second Brain выкл/вкл (или перезапуск Obsidian).
2. **Вкладка настроек**: Настройки → Сторонние плагины → **Second Brain** — должны быть
   выключатели «Вести журнал», 4 уровня, «Писать результаты проверок», лимит строк,
   кнопка «Очистить», режим подписей. Выключите `info` — создайте любой объект —
   в журнале не должно появиться записи о создании; включите обратно.
3. **Команда show-log**: палитра `Ctrl+P` → «Показать журнал плагина (show-log)»:
   видны записи загрузки плагина; нажмите «Живой режим: выкл» (станет «вкл») и, не
   закрывая окна, создайте объект через create-object — строка появится в окне сразу.
4. Фильтр: выберите «Ошибки (error)» — останутся только записи ошибок.
5. Файлы хранилища: появились `.sb/settings.json` и `.sb/logs/plugin-log.jsonl`
   (в проводнике — папка `.sb` скрытая; в Obsidian видна, если включён показ
   скрытых папок, либо проверьте проводником Windows).
6. Быстрый прогон A2 (регресс): создайте тип (например `note`), создайте объект этого
   типа, запустите validate-object — в журнале должны появиться записи `creation`
   и `validation`.
