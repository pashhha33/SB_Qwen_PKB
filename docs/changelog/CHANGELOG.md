# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по semver
(см. [[glossary|глоссарий]]: «semver», «ломающее изменение»).

> [!warning] Правило повышения версии метамодели
> - **MAJOR** (1.0.0 → 2.0.0): ломающее изменение — старая заметка перестаёт быть правильной.
>   Например: переименовали тип, удалили поле, обязательным стало необязательное.
> - **MINOR** (0.1.0 → 0.2.0): добавили тип, поле, связь, правило-предупреждение. Старые заметки не ломаются.
> - **PATCH** (0.1.0 → 0.1.1): исправление опечаток, уточнение формулировок, правки в примерах.

Каждая запись обязана содержать: версию, дату, что изменилось, **почему**, нужна ли миграция, ссылку на ADR/решение.
