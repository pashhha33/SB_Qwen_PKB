# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по semver
(см. [[glossary|глоссарий]]: «semver», «ломающее изменение»).

> [!warning] Правило повышения версии метамодели
> - **MAJOR** (1.0.0 → 2.0.0): ломающее изменение — старая заметка перестаёт быть правильной.
>   Например: переименовали тип, удалили поле, обязательным стало необязательное.
> - **MINOR** (0.1.0 → 0.2.0): добавили тип, поле, связь, правило-предупреждение. Старые заметки не ломаются.
> - **PATCH** (0.1.0 → 0.1.1): исправление опечаток, уточнение формулировок, правки в примерах.

Каждая запись обязана содержать: версию, дату, что изменилось, **почему**, нужна ли миграция, ссылку на ADR/решение.

## [Unreleased]

### Добавлено
- Каркас документации: структура `docs/`, шаблоны ADR, сущности, связи, decision log, changelog, глоссария, правила валидации, интеграции.
- Файл «Карта проекта» (`docs/project-map/PROJECT_MAP.md`) как страховка от потери контекста.
- Глоссарий v0.1.0 с первичным набором терминов.
- Чек-лист «Метамодель готова к реализации плагина» (`docs/roadmap/readiness-checklist.md`), блоки A–F.
- **Фаза 1 — диагностика исходных черновиков метамодели:**
  - `docs/inbox/` — неизменяемые копии трёх файлов пользователя + README с правилом папки и таблицей актуальности версий;
  - `docs/metamodel/analysis-01-incoming-drafts.md` — диагноз: приём материалов, объяснение устройства модели, сравнение v1.0 и v1.1, пять главных проблем, порядок решения (шаги 0–9), десять рекомендаций R-01…R-10;
  - `docs/metamodel/analysis-contradictions.md` — реестр из 52 записей: 16 противоречий (C-01…C-16), 7 дублей (D-01…D-07), 14 неясностей (U-01…U-14), 15 пробелов (G-01…G-15). Каждой записи присвоен идентификатор и уровень критичности.
- Глоссарий дополнен 28 терминами из исходных черновиков (ULID, UUID v7, префикс типа, таксономия, фасет, категория, реификация связи, источник истины, инвариант, DOM-интеграция, адаптер, bootstrapping и др.).

### Изменено
- Карта проекта поднята до v0.2.0: фаза 1 выполнена, добавлены раздел «Что за модель», результаты Фазы 1, инвентарь артефактов, блокеры и новые риски.
- Decision log: добавлены записи DL-011…DL-022 (одна принята, остальные в статусе `предложено`).
- `docs/README.md`: в дерево каталогов добавлены `docs/inbox/` и два файла анализа.

### Удалено
- Ничего. Исходные черновики не редактируются и не удаляются (DL-011).

### Требует миграции
- Нет. Метамодель ещё не версионируется: версия остаётся `0.0.0`, ни одного содержательного решения не принято.

### Ссылки
- DL-011…DL-022 в [[decision-log]]
- Реестр проблем: `docs/metamodel/analysis-contradictions.md`
