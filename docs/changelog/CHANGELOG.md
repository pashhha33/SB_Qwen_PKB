# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по semver
(см. [[glossary|глоссарий]]: «semver», «ломающее изменение»).

> [!warning] Правило повышения версии метамодели
> - **MAJOR** (1.0.0 → 2.0.0): ломающее изменение — старая заметка перестаёт быть правильной.
>   Например: переименовали тип, удалили поле, обязательным стало необязательное.
> - **MINOR** (0.1.0 → 0.2.0): добавили тип, поле, связь, правило-предупреждение. Старые заметки не ломаются.
> - **PATCH** (0.1.0 → 0.1.1): исправление опечаток, уточнение формулировок, правки в примерах.

Каждая запись обязана содержать: версию, дату, что изменилось, **почему**, нужна ли миграция, ссылку на ADR/решение.

## [0.7.0] — 2026-10-22

Закрыты четыре решения, предложенные в `0.6.0`. Ответы пользователя: рейтинг — **A**, состав
`book_format` — **B**, условные свойства — **A**, главы пакетом — **A**.

### Изменено
- **`book_format` закрыто и сокращено с шести значений до пяти**: `file`, `card`, `web_novel`,
  `print`, `audio`. Значение `online_literature` **не введено** — «сетевая литература» является
  надмножеством веб-новелы и отдельного набора свойств не требует; различать произведения внутри
  веб-новел можно категорией фасета `genre` или свободной меткой (DL-121, DL-135).
  Закрытых перечислений стало **16 из 19**.
- Условные свойства `platform`, `publication_status`, `release_cadence`, `last_chapter_on`
  включаются теперь только при `format = web_novel` (было — при двух значениях).
- Правило `book.format.enum`: «список из пяти значений» вместо шести.

### Принято (из статуса «предложено»)
- **DL-115, DL-116** — `rating` хранится как **целое 1–10** и показывается звёздами
  (`★★★★★★★☆☆☆ 7/10`) через `display.renderer: stars`, `display.scale_max: 10`.
  Шкала единая для всех типов объектов, специального поля не вводится.
- **DL-121** — состав `book_format` (вариант B).
- **DL-122** — перечень из 10 условных свойств книги, включаемых форматом (вариант A);
  недостающие свойства добавляются командами плагина.
- **DL-133** — автоперенумерации глав нет: разрыв нумерации виден как warning
  `relation.order.no_gap`, перенумерация — явная команда `sb-renumber-chapters` (этап 2).
- **DL-125, DL-118** (подтверждены пакетом) — `contains` хранится, `part_of` вычисляется;
  `chapter_count` не хранится, а считается как число связей.

### Добавлено
- Разъяснение границы `format` и `media_kind`: `format` — «в каком виде я это веду»,
  `media_kind` — «что за файл лежит в хранилище». Аудиокнига может быть заведена как `book`
  с `format: audio` **и** иметь связанный объект `media` с `media_kind: audio` — это разные
  сведения (DL-135).

### Миграция
Не требуется: версия до 1.0.0, экземпляров в хранилище нет. Сокращение перечисления
`book_format` **стало бы ломающим изменением после 1.0.0** (заметки со значением
`online_literature` перестали бы проходить валидацию) — зафиксировано заранее как образец
миграции «сужение перечисления» для `docs/metamodel/10-migration-rules.md` (шаг 8).

## [0.1.0] — 2026-10-22

Первая версия метамодели Second Brain. Зафиксирован фундамент: идентичность, хранение, имена полей,

### Добавлено
- [[../adr/ADR-001-identity-and-file-naming|ADR-001]] — ULID как идентификатор, непрозрачное имя файла,
  трёхуровневая стратегия читаемости, меры M1–M7. Причина: пользователь выбрал вариант A и указал, что
  вариант B не устраняет проблему, а лишь уменьшает её. Закрывает C-01, C-16.
- [[../adr/ADR-002-source-of-truth|ADR-002]] — определения метамодели в Markdown-заметках хранилища,
  `.sb/` только для служебных данных. Причина: сохранение принципа самоопределяющейся модели и сокращение
  объёма кода. Закрывает C-02.
- [[../adr/ADR-003-bilingual-keys-and-label-layer|ADR-003]] — английские технические ключи + русские подписи
  `label` + слой отображения `LabelResolver` с режимами `view`/`source`. Причина: требование «идентификаторы
  на английском» при удобстве для русскоязычного пользователя. Закрывает C-06, частично C-03.
- [[../adr/ADR-004-first-pass-scope-and-command-driven-authoring|ADR-004]] — первый проход: реестр всех
  ~40 типов + детальное описание ядра из 8; создание элементов метамодели только командами плагина.
  Закрывает G-01, D-01, частично G-02 и G-06.
- [[../integrations/research-front-matter-title-stability]] — исследование стабильности плагина
  Front Matter Title: хронология инцидентов, состояние на 2026-10-22, три практических следствия.
- Таблица соответствия старых русских имён полей новым английским ключам (ADR-003).

### Изменено

### Удалено

### Требует миграции
