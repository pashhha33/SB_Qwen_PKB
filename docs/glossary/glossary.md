# Глоссарий

> [!info] Как пользоваться
> Таблица ниже — единый источник правды по терминам. В других документах вместо повторного объяснения
> даётся ссылка: «см. [[glossary|глоссарий]]».

## Как читать статусы

| Статус | Что значит |
|---|---|
| `активный` | Термин используется в проекте в этом значении |
| `устаревший` | Раньше использовался, сейчас — нет. Оставлен для истории |
| `заменён` | Значение изменилось. Рядом есть новая запись с тем же термином |

## Проверка глоссария

Проводится в конце каждой фазы:

- [ ] Нет ли двух записей с одним и тем же смыслом, но разными словами (дубли)?
- [ ] Нет ли противоречий: один термин объяснён по-разному в двух местах?
- [ ] Нет ли записей со статусом `активный`, которые больше нигде не используются?
- [ ] Все ли термины из последних артефактов занесены?
- [ ] Понятны ли определения человеку без технического образования (нет объяснений через необъяснённые термины)?
