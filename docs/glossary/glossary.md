# Глоссарий

> [!info] Как пользоваться
> Таблица ниже — единый источник правды по терминам. В других документах вместо повторного объяснения
> даётся ссылка: «см. [[glossary|глоссарий]]».

## Как читать статусы

| Статус | Что значит |
|---|---|
| `активный` | Термин используется в проекте в этом значении |
| `устаревший` | Раньше использовался, сейчас — нет. Оставлен для истории |
| `заменён` | Значение изменилось. Рядом есть новая запись с тем же термином |
