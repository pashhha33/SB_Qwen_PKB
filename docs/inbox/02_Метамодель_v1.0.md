# Метамодель

## 1. Тип объекта

Физическое ядро:

```yaml
---
id: OBJECT-TYPE-000001
название: Человек
тип_объекта: тип_объекта

родительский_тип:
  - "[[Контекст — OBJECT-TYPE-000006]]"

описание: Объект, представляющий конкретного человека.
---
```

Правило:

Только непосредственный родитель.

`семейство` отдельно не хранится.

---

# 2. Тип свойства

Восемь самостоятельных объектов:

PROPERTY-TYPE-000001 — Текст  
PROPERTY-TYPE-000002 — Число  
PROPERTY-TYPE-000003 — Дата  
PROPERTY-TYPE-000004 — Дата и время  
PROPERTY-TYPE-000005 — Логическое  
PROPERTY-TYPE-000006 — Список  
PROPERTY-TYPE-000007 — Ссылка  
PROPERTY-TYPE-000008 — Список ссылок

Набор фундаментальных типов закрыт для текущей версии.

---

# 3. Свойство

```yaml
---
id: PROPERTY-000001
название: Название
тип_объекта: свойство

тип_значения: "[[Текст — PROPERTY-TYPE-000001]]"

кардинальность: 1
обязательность: обязательное

определение: Читаемое человеком название объекта.

область_применения:
  - универсальное

уровень: универсальное

жизненный_цикл: стандартное
---
```

Технические ограничения не входят в семантическое ядро.

Они определяются при реализации FileClass.

---

# 4. Тип отношения

```yaml
---
id: RELATION-TYPE-000001
название: Автор
тип_объекта: тип_отношения

прямое_название: автор
обратное_название: автор произведения
направление: направленное

рекомендуемый_субъект:
  - "[[Произведение — OBJECT-TYPE-000003]]"

рекомендуемый_объект:
  - "[[Человек — OBJECT-TYPE-000006]]"

кардинальность: 0..N
правило_уникальности: уникальная_связь
---
```

---

# 5. Отношение

```yaml
---
id: RELATION-000001
название: Автор «Мастер и Маргарита»
тип_объекта: отношение

субъект: "[[Мастер и Маргарита — BOOK-000001]]"
тип_отношения: "[[Автор — RELATION-TYPE-000001]]"
объект: "[[Михаил Булгаков — PERSON-000001]]"
---
```

Дополнительные свойства локальны:

- порядок;
    
- основное;
    
- дата_начала;
    
- дата_окончания;
    
- источник;
    
- контекст;
    
- описание.

# 6. Таксономия

```yaml
---
id: TAXONOMY-000001
название: Жанры
тип_объекта: таксономия

режим_иерархии: строгая
кардинальность_назначения: 0..N

допустимые_типы_объектов:
  - "[[Книга — OBJECT-TYPE-000001]]"
  - "[[Веб-новела — OBJECT-TYPE-000002]]"
  - "[[Фильм — OBJECT-TYPE-000003]]"
  - "[[Сериал — OBJECT-TYPE-000004]]"

требование_корня: несколько
---
```

# 7. Категория

```yaml
---
id: CATEGORY-000001

таксономия: "[[Жанры — TAXONOMY-000001]]"

  - "[[Научная фантастика — CATEGORY-000002]]"

```

# 10. Главная архитектурная цепочка

Тип свойства  
↓  
Свойство  
↓  
Тип объекта  
↓  
Экземпляр объекта  
↓  
Значение свойства

Отдельно:

Тип отношения  
↓

↓  
Субъект ↔ Объект

Таксономия  
↓  
Категория  
↓  
Объект

Объект  
↓  
Представление  
↓  
Base

Автоматизация  
↓  
реализация
