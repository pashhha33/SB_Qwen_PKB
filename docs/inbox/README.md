# Входящие черновики

> [!warning] Правило папки
> Здесь лежат **исходные материалы пользователя** — то, с чего начался проект.
> Эти файлы не редактируются и не удаляются. Все правки делаются в `docs/metamodel/`,
> а происхождение каждого решения отслеживается через [[../decisions/decision-log|decision log]] и ADR.
>
> Зачем: через месяц нужно будет ответить «а что было в исходнике?» — и ответ должен быть точным,
> а не по памяти.

## Актуальность

По сообщению пользователя: **при разночтениях более актуальна последняя созданная версия**.

| Документ | Считается | Основание |
|---|---|---|
| `02_Метамодель_v1.1_черновик.md` | основной источник по метамодели | последняя редакция |
| `02_Метамодель_v1.0.md` | предыдущая версия того же документа (DOC-000002) | заменена v1.1, но сохраняет разделы, которые v1.1 не переписывала |
| `01_Second_Brain_Architecture_Specification.md` | отдельный документ (DOC-000001), статус «утверждён» | **не переписан** в v1.1, поэтому содержит положения, которые v1.1 отменил или изменил |

> [!important] Следствие, требующее решения
> Формально спецификация 01 имеет статус «утверждён», а метамодель v1.1 — «черновик».
> При этом v1.1 меняет решения, зафиксированные в 01 (формат ID, имя файла, состав классификации).
> Возникает ситуация: утверждённый документ противоречит более новому черновику.
> Это противоречие C-01 в [[analysis-contradictions|реестре противоречий]].
