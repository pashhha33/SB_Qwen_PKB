**Некорректный** экземпляр `book` (батч 2, D4) — файл намеренно не проходит схему.
Разбор нарушений:

| Нарушение | Правило реестра | Кто ловит | Сообщение пользователю |
|---|---|---|---|
| Нет `id` | `object.id.format` (И1) | **схема** (`system_core.required`) | «У книги нет идентификатора. Создайте её командой плагина» |
| Нет `created_at` / `updated_at` | `object.created_at.required` | **схема** (`system_core.required`) | «Дата создания будет добавлена при сохранении через плагин» |
| Нет `author` | `book.author.required` | **схема** (`required` + `minItems: 1`) | «У книги должен быть указан хотя бы один автор» |
| `read_status: читаю` — кириллица, не из списка | `book.read_status.enum`, `enum.value.no_mixed_script` | **схема** (`enum`) | «Статус прочтения может быть только одним из: planned, reading, read, abandoned, not_planned» |
| `rating: 12` | `book.rating.range` | **схема** (`integer 1–10`) | «Оценка должна быть целым числом от 1 до 10» |
| `format: журнал` | `book.format.enum` | **схема** (`enum`) | «Формат — одно из пяти значений: file, card, web_novel, print, audio» |
| `finished_on: "2026-13-45"` | `date.range.valid` | **схема частично** (паттерн `date` отсекает месяц 13 и день 45); полная семантика (например, `2026-02-31` — паттерн пропустит) — runner | «Месяц 13 и день 45 не существуют» |
| Нет `aliases` | `object.aliases.first_is_title` (И4) | runner (warning) | «Первый псевдоним должен совпадать с названием. Плагин может добавить его автоматически» |
| Нет категорий | `book.genre.cardinality` | runner (error; `minItems: 1` в схеме ловит только пустой список — принадлежность фасету `genre` межобъектная) | «Книге нужна минимум одна категория жанра» |

Обратите внимание на разделение труда (принцип DL-222): схема ловит **внутрифайловое**,
runner — **межобъектное** и то, что JSON Schema выразить не может (сравнение двух дат,
принадлежность категории фасету, существование файла-цели).
