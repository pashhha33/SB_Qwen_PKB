**Некорректный** экземпляр `knowledge` (батч 4, D4) — файл намеренно не проходит проверку;
тело пустое. Разбор нарушений:

| Нарушение | Правило реестра | Кто ловит | Сообщение пользователю |
|---|---|---|---|
| Нет `created_at` / `updated_at` | `object.created_at.required` | **схема** (`system_core.required`) | «Дата создания будет добавлена при сохранении через плагин» |
| `aliases[0] != title` («Другая формулировка» ≠ «Мысль») | `object.aliases.first_is_title` (И4) | runner (warning, автоисправление — случай 2 severity-policy) | «Первый псевдоним должен совпадать с названием» |
| Категорий две, а у фасета «Вид знания» `assignment_cardinality: 0..1` | `assignment.cardinality` | runner (error, межобъектное: нужно знать фасет каждой категории) | «Вид знания — не более одной категории» |
| `"[[CATEGORY-….md\|…]]"` — не ULID | `link.canonical.format` | **схема** (паттерн `link_category`) + runner | «Ссылка на категорию malformed: ожидается CATEGORY-{ULID}.md» |
| `источник:` — русский ключ | ADR-003 (ключи — английский `snake_case`) | runner (warning «вне схемы»: ключ не объявлен; объявленное свойство — `source`) | «Неизвестное поле „источник“. Возможно, вы имели в виду „Источник“ (`source`)?» |
| `related_to` → `media` | `value.reference.target_type` | **схема** (anyOf четырёх ядерных типов) + runner | «„Связано с“ у знания ведёт на knowledge/book/person/project, не на обёртку медиа» |
| Пустое тело | `knowledge.body.not_empty` | runner (warning, группа N) — схема тело не видит | «Знание без текста тезиса пусто: сформулируйте мысль» |
| `id` совпадает с другим примером (`valid-01-conclusion.md`) | `object.id.unique` (И1) | runner (error, межобъектное) — в рамках примеров иллюстративно (DL-019) | «Этот id уже используется другой записью» |

Обратите внимание: у знания **нет обязательных предметных свойств** — единственное
предметное поле `source` необязательно (K1, DL-215); ошибки этого примера — про форму
ссылок, язык ключей и кардинальность категорий, а не про состав полей.

- Схема: `schema/entities/knowledge.schema.json`.
