# Шаблоны заметок — пункт D5 чек-листа готовности

**Что это.** Заготовки для команд создания (ADR-004): команда `create-object <тип>`
берёт шаблон, подставляет служебные поля и открывает заметку. Плейсхолдеры
(`{…}`) — **не данные**: они не обязаны проходить валидацию; прогонщик
(`npm run check`) этот каталог не проверяет.

**Что подставляет команда (руками не заполнять):**

| Плейсхолдер | Значение |
|---|---|
| `{ULID}` | Новый ULID (монотонный, Crockford Base32 без I/L/O/U) |
| `{NOW}` | Текущее время, формат `YYYY-MM-DDTHH:mm` (без секунд) |
| `{TITLE}` | Название из аргумента команды; `aliases[0]` = `title` (И4) |
| `{PREFIX}` | Префикс типа из определения `object_type` (`BOOK-`, `PERSON-`…) |

**Соглашения:** даты — в кавычках (иначе YAML-парсер вернёт объект `Date`,
а норма — строка, DL-228); `created_at`/`updated_at` — строки **без кавычек**
и без секунд; необязательные поля закомментированы (`#`) — команда или пользователь
раскомментирует при заполнении; неизвестные поля допускаются (warning runner'а,
М-принципы) — шаблон содержит минимум.

**Состав (13 шаблонов):** book, person, chapter, media, project, knowledge —
6 предметных типов; object_type, property, relation_type, taxonomy, facet,
category — 6 типов слоя 2; `relation-row.json` — строка `.jsonl`-связи
(создаётся командами связей, не заметкой). Абстрактные `work`/`activity`
шаблонов не имеют — экземпляров не существует (И3, DL-214).
